# Flower Recognition Using CNN

## Overview
A flower image classification project using
Convolutional Neural Networks (CNN) with
TensorFlow and Keras.

## Flower Categories
- Dandelion
- Daisy
- Tulips
- Sunflowers
- Roses

## Technologies
- Python
- TensorFlow
- Keras
- TensorFlow Datasets
- NumPy
- Matplotlib
- Scikit-learn

## Model Architecture
- Input: 64x64 RGB image
- Data Augmentation
- Three Convolutional Blocks
- Max Pooling
- Global Average Pooling
- Dense Layer (128 neurons)
- Dropout (0.25)
- Softmax Output (5 classes)

## Dataset
TensorFlow Flowers Dataset

Training: 80%
Validation: 10%
Testing: 10%

## How to Run

Install dependencies:

pip install -r requirements.txt

Launch notebook:

jupyter notebook

Open Flower_Recognition_CNN_Final.ipynb
